# Superseded FIRON/A16 ablation

These partial results use the final FIRON W4 weights, with activation quantization removed. They are not an original-BF16 GPTQ baseline and are excluded from the current paper tables. The user selected an independent BF16-to-GPTQ control instead.

Original launch/settings paths point to qwen/w4a16; this directory was moved intact to qwen/firon_a16_ablation after the last active task finished. No scores or raw samples were deleted.
