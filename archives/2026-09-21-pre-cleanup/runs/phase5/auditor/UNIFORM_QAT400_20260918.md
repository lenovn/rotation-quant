## Full method identity and parent chain

The completed run is `runs/phase5/llama32-1b/uniform-qat400-s42`, exporting `checkpoint-0400/static_w4a8.pt`. This is a complete Uniform QAT control, **not the historical B100 INT8 format overlay**. The live settings, each stage result and each saved package metadata agree on the exact chain:

`uniform-initial-s42/static_w4a8.pt` → `uniform-down-round-s42/static_w4a8.pt` → `uniform-range-s42/static_w4a8.pt` → `uniform-down-readapt-s42/static_w4a8.pt` → `uniform-qat400-s42/checkpoint-0400/static_w4a8.pt`.

The initial package materialized the B100 parent with the existing train-only down INT8 calibration scales. It was then independently passed through down neighbor optimization, down range contraction, down readaptation, and 400 full-backbone QAT updates. The three PTQ stages were independently audited in `UNIFORM_POSTPROCESS_20260918.md` with their finite budgets, train-only selection and actual INT8 operators; this audit rechecked the saved chain identities and all-INT8 package formats.

The final package contains **112 W4 matrices and 112 INT8 activation quantizers**, including all 16 down projections. No SP2 activation record remains. All 112 final activation scales differ from the QAT parent, providing direct artifact evidence that scales were updated during QAT. Parameter group labels remain W112/SA96/SW112/SP2-group16 because the legacy group name denotes down scales; it does not identify the actual activation format. The saved source uses actual quantizer type in `prepare_student`, so down INT8 uses INT8 scale learning. This operator/learning path also has the earlier independent CPU tests recorded in `UNIFORM_CPU_20260918.md`.
